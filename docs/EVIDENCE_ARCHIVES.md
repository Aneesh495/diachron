# Experimental evidence archives

Research archives preserve an executed campaign, including failures and
unconverged chains. A prerelease archive and a green execution workflow do
not certify full scientific acceptance. Each job records its exact source,
input identities, native binary digest, commands, elapsed time and exit codes.

Code is MIT licensed. IE-CoR v1.2.1 lexical source and derived character
columns retain attribution under CC BY 4.0. Glottolog 5.3 metadata is CC BY
4.0. EDH source-derived inscription records retain attribution to the
Epigraphic Database Heidelberg, Heidelberg Academy of Sciences and Humanities,
under CC BY-SA 4.0. Those records keep their source URLs and bibliographies.
The corresponding component licenses apply to source-derived records in the
archive; the code license does not replace them. Exact source and license
links are in the included manifests and observed-data card.

Archives include an internal SHA-256 inventory and an external compressed-file
digest. Before removing unique local evidence, download the remote archive,
check byte identity, and verify restoration of every archived file. Keep
acquisition inputs separate from executable code. Restoring a data archive
must reject absolute paths, path traversal, links, oversized members and files
outside the declared inventory.

Observed sensitivity shards share one source, input fingerprint, budget and
predeclared protocol. Assembly requires every named configuration and retains
all chain draws. Predictive partitions and per-character scores stay with their
complete training bundles. Concept bootstrap intervals describe variation across
concepts and do not replace convergence diagnostics.
